# Evidence Clips — Not Included in This Branch

The `backend/evidence_clips/` folder is **not included** in this Git branch.

## Why

The evidence clips folder contains **320 MP4 files totalling approximately 4.1 GB**.  
These are automatically generated by the system at runtime whenever the AI confirms a threat — they are not static assets and grow with each demo session.

Including them would make the repository extremely heavy to clone and provide no benefit, since they are regenerated automatically during any demo run.

## How Evidence Clips Are Generated

1. Start the backend and run any demo clip (EXAMPLE-01, EXAMPLE-02, or EXAMPLE-03).
2. When the Decision Layer V2 confirms a threat (CONFIRMED state), the system automatically:
   - Records a ~30-second MP4 clip around the incident
   - Saves a thumbnail JPEG
   - Writes a chain-of-custody entry to `evidence_ledger.jsonl`
   - Sends a Telegram alert with snapshot (if configured)
3. The clip appears in the **Incidents** tab of the dashboard.

## Where Clips Are Stored

After generating, clips are saved to:
```
backend/evidence_clips/alert-<timestamp>-<hash>.mp4
backend/thumbnails/alert-<timestamp>.jpg
```

Both folders are created automatically when the backend starts. You do not need to create them manually.

## Download Evidence After Demo

To export evidence from a demo session for presentation:
1. Open the dashboard → **Incidents** tab
2. Click any alert → **Download Evidence Clip**
3. Or use the API: `GET /download_evidence/{alert_id}`
