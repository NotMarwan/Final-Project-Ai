```text
You are an expert academic presentation strategist, technical storyteller, and university project defense coach.

I want you to create a highly professional, persuasive, academically strong midterm presentation package for our graduation project. The presentation must summarize our real implemented work, reflect the true technical depth of the project, and help ensure the project is evaluated fairly and not underestimated.

Important constraints:
- Do NOT turn this into a generic AI slide deck.
- Do NOT oversell unfinished work.
- Present the project honestly as an advanced and working midterm prototype.
- Emphasize what is already implemented and demonstrable.
- The output must feel suitable for university examiners and a formal academic setting.
- The presentation should be visually clean, technically credible, and exciting without sounding exaggerated.

## Project Identity

- Official Project Title: Deep Learning-Based Real-Time Physical Violence Detection for Intelligent Surveillance
- System Name: AI Sentinel
- Course: Graduation Project Phase 2
- Project Type: Applied / Practical Graduation Project
- Domain: Intelligent Surveillance, Computer Vision, Real-Time Security Monitoring

## What Our System Actually Does

AI Sentinel is a real-time intelligent surveillance system that analyzes camera/video streams to detect physical violence and security threats, generate live alerts, preserve digital evidence, and produce incident documentation.

## What Is Already Implemented

The presentation must reflect these implemented or integrated components:

1. Frontend dashboard built with Next.js
2. Backend service built with FastAPI
3. Real-time or near-real-time video monitoring pipeline
4. Violence inference pipeline based on X3D architecture
5. 32-frame rolling analysis window
6. Alert streaming using SSE
7. Incident/evidence handling
8. PDF incident reporting
9. Evidence storage and evidence integrity workflow
10. Threat fusion logic
11. Weapon signal module
12. Audio risk analysis module
13. Face intelligence/privacy-aware support
14. Camera switching / source handling

## Core Academic Message

This project is not just a video classifier.
It is a complete operational pipeline:

Detection -> Alert -> Evidence -> Incident Review -> Report

That message must appear clearly across the presentation.

## What I Need You To Produce

Please produce the entire output in well-structured Markdown with clear headings and tables where appropriate.

I want the following sections:

### 1) Presentation Strategy
Give a short strategy explaining how we should position the project in front of examiners so they understand:
- the practical value,
- the actual implemented depth,
- the academic quality,
- and why this is a strong midterm prototype.

### 2) Slide-by-Slide Deck Plan
Create a 10 to 12 slide academic presentation outline.
For each slide, provide:
- Slide title
- Slide objective
- Exact bullet content
- Recommended visual or figure
- Short speaker notes

The slide flow should feel natural, persuasive, and suitable for a midterm defense.

### 3) Demo Flow
Provide a clean 3-to-5-minute demo scenario that proves the system is working without unnecessary risk.
The demo should prioritize reliability and clarity.

### 4) Judges Evaluation Form
Create a polished supplemental evaluation form for examiners.
It must:
- look formal and academic,
- align with common project evaluation dimensions,
- highlight strengths such as architecture, technical integration, real-time capability, evidence handling, originality, and practical value,
- and be suitable for printing or attaching as an appendix.

Provide it as a neat table out of 100 points.

### 5) Q&A Defense Kit
Predict at least 8 likely examiner questions and provide strong, short, academic answers.
Questions should include topics such as:
- real-world feasibility,
- why this is not just a simple AI classifier,
- camera limitations,
- privacy,
- system reliability,
- evidence integrity,
- what is complete now versus what remains for the final stage.

### 6) Speaking Roles
Propose a smart speaking-role split for a team of 5 students.

### 7) Final Verbal Opening and Closing
Write:
- one strong opening script of about 30–45 seconds
- one strong closing script of about 20–30 seconds

## Tone and Style Requirements

- Professional
- Academic
- Confident
- Honest
- Structured
- Clear enough to be directly used in slide preparation

## Additional Guidance

Please present the project as:
"an advanced working midterm prototype with real implemented components and a clear path to final completion."

Avoid describing it as:
- just an idea
- only a concept
- or unfinished in a weak way

Instead, present it as:
- already implemented at the core level,
- demonstrable,
- integrated across frontend, backend, AI, and reporting,
- and ready for continued expansion in the final phase.

If useful, you may write the explanation in Arabic, but keep slide titles and technical terminology in English.
```
