# EXP-21 Score calibration (temperature scaling on independently labeled held-out scores)

Pre-registered BEFORE results. Workstream WT-20 (DecisionCalibration), slices S-05/S-20 tooling (`bench/calibrate.py`). Method: binary temperature scaling (Guo et al., ICML 2017, https://proceedings.mlr.press/v70/guo17a.html) with deterministic log-grid fit, no optimizer dependency.

- Hypothesis: temperature scaling fit on a **calibration split** of independently labeled scores reduces held-out (test-split) NLL and ECE versus the uncalibrated identity (T=1), so that `calibratedProbability` can be reported as a validated quantity (G-06) instead of `unverified` raw scores; clip-score aggregation `max` over window scores (rare-event primary) is compared against `mean` as a pre-registered variant axis (selection on calibration-split NLL only).
- Requirement link: G-06 (calibration artifact + startup refusal), F-40 (calibration profile ingestion), SC-5 (policy thresholds remain uncalibrated operating points), WT-06 research R2 (calibration), measurement rules (calibrated probability vs raw score vs severity labeled separately).
- Baseline: uncalibrated scores (identity T=1) from WT-12's eval harness on the violence model `backend/best_model.pt` (sha256 2c8222d3…20d01; harness revision + model hash recorded in the artifact `model_sha256`/`input_sha256` at run time); input = `bench/calibrate.py` schema `{model_sha256, observations:[{clip_id, source_sha256, split, label, score, label_source}]}` with the `max`-aggregate file as primary and `mean`-aggregate as variant; data split = WT-12 manifest, `calibration` and `test` both containing both classes, unique clip_id + unique source_sha256 enforced (leak guard), session-disjoint; source mode = **file-media** auxiliary-domain KTH (160x120 static camera; NOT live, NOT in-domain CCTV); label provenance = `publisher` only; workload = offline fit + evaluation (no inference).
- Candidate: `temperature` on a fixed 601-point log grid [0.05 … 400] plus 1.0; fit objective = calibration-split NLL; variant axis = clip aggregation {max, mean} (both files produced by WT-12 with declared `aggregation` header). EMA-smoothed scores are NOT valid calibration inputs — inputs are raw model scores (per window then aggregated); if WT-19 supplies raw pre-EMA margins, a second pre-registered card may fit on margins.
- Success criteria (defined BEFORE inspecting results): (1) on the held-out **test split**, `ece_after < ece_before` AND `nll_after < nll_after(T=1) = nll_before` for the chosen aggregation; (2) both classes present independently in each split (tool-enforced); (3) artifact passes `calibration_utils.validate_calibration_artifact` (schema_version 1, finite temperature > 0, model_sha256 bound, nonempty `limitations` stating auxiliary-domain + staged-punching validity limits); (4) ECE reported with bin count (15) + n per bin group and denominators (n_calibration clips, n_test clips, n_pos/n_neg per split). Aggregation variant selection: lower calibration-split NLL; ties → `max`.
- Failure criteria / rollback: ECE/NLL do not improve on test → **no artifact is published** and runtime `calibrationStatus` stays `unverified`; pseudo/synthetic/publisher-unverifiable labels → tool refuses (ValueError) and no artifact; artifact produced from a run without split-separation validation → invalid. Rollback = `backend/model_calibration.json` remains absent; `calibration_utils` refuses startup without the loud dev override (G-06 machinery unaffected).
