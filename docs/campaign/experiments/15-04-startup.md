# EXP-15.04 Startup stages (G-13): spawn → load → first completed inference, cold vs warm

- Hypothesis: Cold startup is dominated by model construction (torch checkpoint load + ONNX session init, sequential violence→weapon→person), while the first completed observation adds little beyond model warmup; the media-reset handshake (models resident) gives a warm path whose first-observation latency is a small fraction of cold spawn→first-observation. Persistent bounded model threads (person ThreadPoolExecutor(1), violence inference executor(1), weapon daemon thread) are retained unchanged.
- Requirement link: WT-15 step 4; G-13 (60 s cold-start budget; stage split required); F-06; reset handshake (F-39) timing.
- Baseline: identical to EXP-15.01 baseline block; measurement chain: parent-side spawn→ready_event (QPC), worker-side startupModelLoadMs (worker-entry→ready), startupFirstFrameMs, startupFirstResultMs, startupFirstObservationMs (first observed model completion — completed-inference discipline), plus reset_handshake_s for the warm leg.
- Candidate: same config; cold leg = fresh process (cold caches, models not resident); warm leg = same process after media-loop reset (models resident). Any startup optimization (e.g. overlapping model construction) is a follow-up candidate only if the stage split shows load dominance; it must then pass a re-run with identical hashes and no new failure.
- Success criteria (defined BEFORE inspecting results): (a) full stage chain measured n≥4 cold spawns, distributions reported; (b) every stage separately attributed (no blended "startup" number); (c) warm leg completes via the reset handshake with ack < 2 s; (d) if a candidate optimization is evaluated: adopt only if spawn→first-observation median improves ≥15% with byte-identical model hashes and zero new failures.
- Failure criteria / rollback: ready_event timeout (>300 s) or first-observation never completing = measured failure recorded as such (startup budget exceeded); any optimization failing (d) is reverted (baseline construction order restored).
- Result: MEASURED (artifact 15-04-startup.json; run A startup block as cold-cache replicate).
